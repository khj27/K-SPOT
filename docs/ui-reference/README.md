# 기존 UI 참고 이미지

이 폴더에는 현재 서비스에 반영할 기존 UI 이미지를 넣습니다.

## 권장 파일명

```text
01-home-desktop.png
01-home-mobile.png
02-content-explore-desktop.png
03-content-detail-desktop.png
04-spot-explore-desktop.png
05-spot-detail-desktop.png
06-planner-form-desktop.png
07-planner-result-desktop.png
08-admin-desktop.png
```

JPG, JPEG, PNG, WebP 형식을 사용할 수 있습니다.

화면이 여러 장이면 숫자와 화면 이름을 붙여 탐색 순서대로 정리합니다. 모바일 디자인이 별도로 있을 경우 파일명 끝에 `-mobile`을 붙입니다.

UI 이미지를 추가한 뒤에는 기존 디자인 분석이 끝날 때까지 `src/app`과 `src/components`를 이미지에 맞춰 직접 덮어쓰지 않습니다.
