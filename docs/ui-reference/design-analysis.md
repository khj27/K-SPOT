# K-SPOT UI 참고 이미지 분석

## 화면 목록

1. 홈: 지도 중심 탐색, 콘텐츠 유형 칩, 선택 장소 상세 패널, 카테고리 진입
2. 콘텐츠 탐색: 3열 카드 목록과 우측 필터
3. 콘텐츠 상세: 대형 히어로, 탭, 촬영지 카드와 보조 정보 패널
4. 지도 탐색: 좌측 필터, 중앙 지도, 우측 검색 결과
5. 장소 상세: 장소 히어로, 핵심 정보, 연관 콘텐츠·후기, 주변 정보
6. 여행 조건 입력: 단계별 선택 폼과 우측 선택 요약
7. 여행 결과: 시간순 일정, 전체 경로 지도, 코스 요약
8. 관리자: 별도 사이드바, 통계 카드, 표, 빠른 작업
9. 관리자 로그인: 좌측 이미지와 우측 로그인 카드
10. CSV 가져오기: 4단계 진행 표시와 업로드 영역
11. 찜한 장소: 필터 칩과 장소 카드 그리드
12. 방문 후기 작성: 평점, 방문 정보, 후기, 사진 첨부
13. 통합 검색: 결과 유형 탭과 유형별 카드 섹션

## 공통 디자인 시스템

- 서비스명: `K-SPOT`
- 기본 배경: 흰색에서 매우 옅은 청회색
- 주요 강조색: 보라색 `#5b4cf5`, 진한 보라색 `#4435dd`
- 본문색: 짙은 남색 `#171a2b`
- 보조 본문색: 청회색 `#667085`
- 카드: 흰색, 12~16px radius, 얇은 회색 테두리, 약한 그림자
- 버튼: 보라색 그라데이션 또는 흰색 외곽선
- 태그: 콘텐츠 유형별 옅은 배경과 작은 pill 형태
- 아이콘: 20~24px 단색 outline
- 레이아웃: 약 246px 좌측 사이드바 + 상단 검색 + 콘텐츠 영역
- 정보 밀도: PC 1536×1024 기준으로 한 화면에 지도·목록·상세를 함께 제공

## 반응형 가정

모바일 참고 이미지는 제공되지 않았다. 900px 이하에서는 좌측 사이드바를 상단 브랜드·가로 메뉴로 전환하고, 지도와 상세 패널은 한 열로 쌓는다. 지도 정보는 동일한 목록으로도 접근할 수 있게 유지한다.

## 구현 원칙

- 제공된 이미지는 시각 참고자료이며 화면 안 사진을 서비스 자산으로 추출하지 않는다.
- 출처가 확인되지 않은 콘텐츠·장소 관계는 UI 검증용 데모로 명시한다.
- 실제 이미지와 관계 데이터는 출처, 확인일, 사용권을 확보한 뒤 교체한다.
