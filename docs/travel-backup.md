# 여행 데이터 백업과 복원

`/mypage`에서 브라우저에 저장한 장소·일정 개수를 확인하고 `/saved`로 이동해 상세 내용을 열 수 있습니다.

## 다른 노트북으로 옮기기

1. 현재 노트북에서 마이페이지 → 여행 데이터 백업 다운로드를 누릅니다.
2. 다운로드한 `kspot-travel-날짜.json` 파일을 다른 노트북으로 옮깁니다.
3. 다른 노트북에서 동일한 K-SPOT 프로젝트를 실행하거나 배포된 사이트를 엽니다.
4. 마이페이지에서 백업 파일을 선택합니다. 표시된 장소·일정 개수를 확인합니다.
5. 기존 데이터에 추가 복원을 누릅니다. 저장한 여행 보기에서 확인합니다.

같은 ID는 현재 기기 값을 유지합니다. 백업에만 있는 항목을 추가하므로 반복 복원해도 중복 생성되지 않습니다. 복원 후 공개 콘텐츠 목록에 없는 장소는 조회 불가로 표시될 수 있습니다.

파일에는 장소 ID와 일정 조건·순서가 포함됩니다. 관리자 계정, 인증키, Firebase 콘텐츠 원본은 포함되지 않습니다. 앱 코드의 GitHub 동기화와 여행 데이터 이전은 별개입니다. 이 기능은 사용자 로그인이나 자동 기기 동기화를 제공하지 않습니다.

백업 최대 크기는 2MB, 장소와 일정 각각 최대 1,000개입니다. 형식 또는 데이터가 잘못되면 복원하지 않습니다. 저장 중 오류가 나면 이전 값으로 되돌리기를 시도하며, 접근 자체가 차단되어 되돌릴 수 없는 경우 일부 반영 가능성을 안내합니다.
