# 기존 여행 자료 이전

현재 찜·일정·최근 본 장소는 로그인 계정의 Firebase에 자동 저장됩니다. 다른 노트북에서는 동일 계정으로 로그인하면 자료를 불러옵니다. JSON 백업 다운로드·복원 화면은 자동 저장 방식으로 대체했습니다.

변경 전에 브라우저에 저장한 자료가 있다면:

1. 해당 브라우저에서 자신의 계정으로 로그인합니다.
2. 마이페이지 → 이전에 브라우저에 저장했던 자료 이전을 펼칩니다.
3. 계정의 이전 로컬 자료 또는 이전 비회원 자료를 선택합니다.
4. Firebase 병합 완료 메시지와 저장한 여행 목록을 확인합니다.

기존 Firebase 자료를 유지하면서 없는 ID만 추가합니다. 과거 로컬 원본은 변경하지 않으며 이후의 새 저장은 Firebase에만 반영됩니다. 공용 브라우저의 비회원 자료를 가져올 때에는 본인 자료인지 확인하세요.

자세한 동작과 제한은 [사용자 계정 안내](user-accounts.md)를 참고하세요.
